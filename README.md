# n8n-nodes-tuneviva

Use TuneViva's public read-only API to get practice score details and MusicXML links by score ID. Create catalogue search links or open the scanner. The scanner runs locally in the user's browser; this node does not upload images or perform recognition. Search generates a link rather than returning search results.

No account or API key is required. Input score IDs are numeric. Review licensing and attribution on each score's TuneViva page. Support: info@tuneviva.com.
